# Дневник лечения псориаза

Мобильное веб-приложение для личного дневника и напоминаний.

## Установка на телефон

1. Включите GitHub Pages для репозитория: **Settings → Pages → Deploy from a branch → master → /(root) → Save**.
2. Дождитесь публикации и откройте адрес GitHub Pages на телефоне.
3. Android / Chrome: меню браузера → «Установить приложение» или «Добавить на главный экран».
4. iPhone / Safari: «Поделиться» → «На экран Домой» → «Добавить».

## Данные и уведомления

- Данные хранятся локально в cookies браузера; сервер и аккаунт не используются.
- Используйте экспорт JSON для резервной копии и переноса на другое устройство.
- Очистка cookies браузера удалит дневник.
- Напоминания проверяются, пока приложение открыто. После полного закрытия приложения уведомления не гарантируются.
- Service Worker кэширует приложение для офлайн-открытия после первой загрузки.

## Важно

Расписание по умолчанию — предварительное заполнение дневника. Проверьте дозировки и частоту приёма по оригинальному назначению врача. Аммифурин и PUVA в приложение не добавлены.
